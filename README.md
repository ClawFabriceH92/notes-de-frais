# Notes de frais

Application Android de saisie et suivi des notes de frais.

## Statut

Dépôt initialisé. Périmètre et interface à valider avant développement.

## Pistes

- Saisie rapide d'une dépense (date, montant, TVA, catégorie, justificatif photo)
- Stockage local (Room), export CSV / PDF par mois
- Totaux par catégorie et par période

## Technique

Kotlin · Jetpack Compose · minSdk à définir
